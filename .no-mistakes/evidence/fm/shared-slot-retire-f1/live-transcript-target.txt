
=== help: the retire command documents --no-live-owner
$ FM_HOME=/tmp/fm-live-f1f3.qIDTLd bin/fm-local-retire-reassigned.sh --help
  | Retire one finished record after Treehouse leased its slot to another task.
  | Usage: FM_HOME=<home> fm-local-retire-reassigned.sh <id> --live-task <id>
  |        [--live-home <home>]
  |        FM_HOME=<home> fm-local-retire-reassigned.sh <id> --no-live-owner
  | 
  | This explicit repair never returns a slot, changes a worktree, deletes a Git
  | ref, stops an endpoint, or reaps a process. Normal teardown stays unchanged.
  | The old endpoint must be dead or missing, its last outcome must be done, and
  | it must have no open decision. Its final outcome must reach the parent channel
  | first; an undelivered outcome refuses. The pool slot, live record, and live
  | endpoint must agree: Treehouse records the slot owner as owner_pid and
  | owner_started_at (epoch milliseconds). That process must still run with that
  | start time, and every foreground process of the live endpoint must descend
  | from it. The proof reads /proc, so a host without it refuses.
  | --no-live-owner retires a record from a shared slot that has no live owner,
  | such as a slot that several finished records name after their workers exited.
  | The scan covers this home, the local root home, and every local home its
  | secondmate registries reach. Every record whose worktree= or home= names the
  | slot must have a dead or missing endpoint. A recorded Treehouse slot owner
  | process must read as stopped from /proc, so a host without it refuses. The
  | slot-owner claim must not name the old task.
  | Another record for the slot must carry a newer spawn_gen epoch (s<epoch>.*),
  | so the old task is not the newest claimant. An equal epoch or an unreadable
  | old epoch refuses, and a record with an unreadable epoch does not count as
  | newer. That newer record then owns the slot's working tree, so its
  | uncommitted state is left for that record's own cleanup and is not counted
  | as the old task's work. The landed proof below otherwise applies unchanged.
  | All reads and retirement hold the project lock and each named task's locks.
  | A scout needs its report and the existing captain-call completion gate.
  | A ship needs its retained fm/<id> branch reachable from a remote, or from
  | local main/master in local-only mode, and not checked out in the slot.
  | With --live-task it also needs a clean shared worktree, so uncommitted ship
  | work refuses. Missing proof refuses: a done line or a merged PR alone cannot
  | prove that subsequent edits landed.
  | 
  | The command archives the old metadata and status under
  | data/<id>/retired-reassigned before removing either active record. It closes
  | the backlog through the existing recovery marker. Before retirement it closes
  | only the old Atlas ticket through bin/fm-atlas-hook.sh land, the teardown
  | discharge: complete the ticket, release its node, and land the node when no
  | other open ticket remains on it. The hook state must then read completed.
  | A refused completion takes the hook's keyed blocker line in the old status log
  | and retains the active record. A refused node landing is written to a fresh
  | status log after retirement, as teardown does. No approval is inferred from a
  | done line.
  | Task check files and other volatile records move into the same archive.
  | Global hook registrations and tasktmp remain untouched for manual inspection.
  | Legacy records without spawn_gen refuse when automatic backlog closure applies.
  | FM_HOME must be explicit. FM_*_OVERRIDE paths follow the normal teardown seam.
  exit=0
  CHECK ok: help names --no-live-owner
